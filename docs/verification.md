## 0.4.1 房间长时运行修复

0.4.1 已通过 Go 全包、142 项 Node 测试，以及针对最终 EXE 的 10 项三人 WebRTC／合成媒体浏览器测试。断线后离开时的消息丢失竞态也已修复，对应测试连续运行 30 次通过。长时验证使用模拟服务端时间，浏览器使用合成媒体；真实采集耐久测试仍需实际设备验证。构建与校验信息见[0.4.1 修复记录](releases/v0.4.1.md)。

最终发行 EXE 还通过完整前端浏览器回归：14 个嵌入资源与源码哈希一致，30 张实际浏览器截图，axe 覆盖 21 个状态且自动识别的 violation 为 0，页面错误与外部资源请求均为 0。两轮实验室的构建及源码／单文件回归也已通过。这些自动回归不等于完整 HIG 或辅助技术认证。

## 0.4.0 历史验收

0.4.0 集成本会话确认的视觉、默认系统声音、完整邀请粘贴及 30 秒自动恢复。已通过 Go 全包、142 项 Node 测试、10 项三人原生 WebRTC／合成媒体端到端测试，以及最终 EXE 的完整前端浏览器检查。后两项明确使用合成视频与音频，不代表真实采集或三台物理设备验收。

恢复测试覆盖成员与房主刷新、活跃页面连接中断后保留采集、连续两次本机服务请求失败后恢复、原身份和房间码、席位不增不减、刷新分享者释放采集、主动离开／结束后刷新不重新加入。房间管理与信令测试还覆盖恢复期限、凭证轮换，以及旧传输的迟到关闭不能删除新传输。

[运行证据](design-research/release-0.4.0-qa/evidence.json)包含 30 张实际浏览器截图，校验了 14 个服务资源与源码一致；页面错误与外部资源请求均为 0。交付 EXE SHA-256 为 `ef192dcd2f45deba97d2eed66f9753ec1c21e2c03e178e1ad66be4a7cea85d63`，构建工具为 Go 1.27.3 Windows amd64，版本输出为 0.4.0。

**HIG 回归结果：** 本轮已覆盖检查通过，axe 对 21 个状态报告 0 项自动识别的 violation，14 条 incomplete 仍待人工判断。不能直接继承旧版 37 项的独立结论，也不声称完整 HIG 或 WCAG 认证。

**视觉验收结果：** 沿用用户确认“比较满意，暂定这一版”的 macOS 桌面视觉，加入与邀请入口按同一控件语言简化；[逐页截图与差异](design-research/release-0.4.0-qa/README.md)独立于 HIG 回归。仍存在 Windows 字体、浏览器控件、项目图标、网页弹窗与 macOS 原生字体、符号和材质的差异，未在真实 Mac 上复验。

真实屏幕／麦克风、三台物理设备、声音隔离听感、后台游戏帧率、不同分辨率鼠标捕获及真实读屏软件仍未完成本版验收。产品行为与使用说明见[0.4.0 版本说明](releases/v0.4.0.md)。

## 真实设备范围

本轮没有采集真实屏幕或麦克风，也没有进行三台实体设备、系统声音隔离听感、后台游戏帧率、不同分辨率鼠标捕获或真实 VoiceOver/Narrator 验证。系统声音即使隔离未确认也可能发送；真实设备的音质、回声、游戏兼容性和帧率仍需公开测试反馈。任意共享内容没有自动字幕或自动转写。
