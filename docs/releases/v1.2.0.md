# v1.2.0 正式版 · LAN / 分享

打开程序就能在独立窗口里和朋友看屏、聊天。这个次版本让三人语音更稳定，让应用窗口共享更直接，也让刷新回房和查找设置更省心。

## 新功能与改进

1. **独立桌面窗口，不怕误关房间。** 支持时，程序通过 Edge 或 Chrome 打开没有浏览器工具栏的应用窗口。房内关闭或刷新前会提醒确认，入口页不会打扰。冰青黛紫品牌图标覆盖 Windows EXE、窗口与网页图标，并提供适合高清显示的尺寸。
2. **首次入房、三人语音更稳。** 程序会尝试自动恢复中断的语音连接。若只剩一位成员未连上，提示会直接显示对方的昵称，点「重试语音连接」即可，无需退房重进。
3. **选中单个应用窗口就开始共享。** 只发该窗口的画面，房间语音照常，不会发应用声音。开播时会出现 3.5 秒轻提示，提示消退后可在顶栏看到「正在共享应用窗口 · 无应用声音」，不占用画面上方的一行。观众不会看到没有声音可调的「共享声音」音量条。共享者底栏只留一个红色「停止共享」，观众仍可切换「只聊语音」与「恢复观看」。
4. **画质上限提高，诊断更完整。** 1080p60 最高 15 Mbps，720p60 最高 8 Mbps，实际随画面与网络变化。本机的单次编码中继将码率上限提高至 24 Mbps。媒体诊断新增关键帧和量化参数（QP，用于判断画面压缩程度）等数据，方便区分编码和传输问题。
5. **刷新回同一个房间，保留本机的听音偏好。** 成员与共享声音的音量、手动静音、只聊语音和文字面板状态可恢复。刷新前已开麦时，回房会尝试用原设备自动开麦，权限被拒或设备不可用时在房内明确提示。刷新不会恢复自己的屏幕共享，也不会保留本机聊天记录。
6. **共享设置一步到位。** 语音房的「共享画质与声音选项」直达设置的「共享」分组，焦点落在画质选项，关闭后回到原按钮。查看长篇诊断时，标题和关闭按钮始终留在弹窗顶部。

## 下载与升级

建议房间内所有成员统一使用 `v1.2.0`。完整解压 Windows x64 ZIP，先查看包内的 `先看这里.html`，再双击 `局域网屏幕共享.exe`。 [下载 Windows x64 ZIP](https://github.com/liyan1775/lan-screen-sharing/releases/download/v1.2.0/lan-screen-sharing-1.2.0-windows-x64.zip) · [发行附件与 SHA-256](https://github.com/liyan1775/lan-screen-sharing/releases/tag/v1.2.0) · [产品介绍](https://liyan1775.github.io/lan-screen-sharing/)

## 验证范围

本机回归使用 Windows x64 成品、Edge、合成媒体与真实 WebRTC，覆盖界面、三人连接、共享和刷新恢复、性能及宣传页。回归会核对 1080p 分辨率、帧率统计和编码设置，60 FPS 是画质目标，不代表本轮通过了固定硬件的高帧率专项验收。真实麦克风和窗口采集、真实游戏帧时间、三台实体电脑和不同网络条件下的表现不由这套自动化测试保证。
