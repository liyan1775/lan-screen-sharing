# v1.0.0 正式版 · LAN / 分享

同一局域网，一起看同一屏。最多三人边看边聊，零账号、零云端中转。全新「冰青瓷银 × 雾紫星环」双模式界面（支持亮白瓷器浅色与暗夜黛青深色），将声音、文字和共享操作收进一行玻璃控制坞，常用看屏工具集中在右上角。

## 核心亮点

1. **有自己的身份** · 取个昵称、选一种头像颜色。昵称、头像和常用偏好保存在本机，重启后继续使用。
2. **更容易找到同网朋友** · 优先推荐真实局域网网卡。支持从附近房间加入，或直接粘贴完整邀请。
3. **麦克风先试再开** · 选择麦克风并在本机试音，按需要用自由麦或按键说话。
4. **看屏工具就在手边** · 局部放大、原尺寸 PNG 截图、全屏、实收画质胶囊，以及浏览器支持时的画中画。
5. **房间有即时反馈** · 可关闭的轻脆提示音和飘屏小表情，让进出、收消息和互动更自然。
6. **文字可以接着用** · 点击消息内的网页链接，或一键复制整条消息。离开房间或刷新后，本机聊天记录清空。
7. **单次编码 + H.264 硬件编码优先与智能兜底** · 分享端只编码一次，由本机 Go 转发器直接分发给两位观众，默认目标 `1080p60`（视频码率上限 `8 Mbps`）。优先协商硬件加速友好的 H.264；若某位成员浏览器暂不支持，全房自动无缝切回 VP8（不断语音、无需重选屏幕）并温和提示具体成员，待该成员离房后自动切回 H.264。设置内可查看实时编解码与浏览器报告的节能状态。

## 下载与升级

每位成员下载并完整解压 Windows x64 ZIP，先打开包内的 `先看这里.html`，再双击 `局域网屏幕共享.exe`。使用桌面版 Edge 或 Chrome，并让所有成员统一到 v1.0.0 后重新创建房间。系统声音由浏览器与采集授权决定。正式版 EXE 未数字签名。 [下载 Windows x64 ZIP](https://github.com/liyan1775/lan-screen-sharing/releases/download/v1.0.0/lan-screen-sharing-1.0.0-windows-x64.zip) · [发行附件与 SHA-256](https://github.com/liyan1775/lan-screen-sharing/releases/tag/v1.0.0) · [产品介绍](https://liyan1775.github.io/lan-screen-sharing/)

## 验证范围

最终 EXE 在同一台 Windows 电脑上的隔离 Edge 实例中通过全套回归。三人同时使用合成麦克风时，单路 1080p 编码与两位观众解码均测得约 59.4–59.5 FPS。1080p60 是默认目标，实际表现随设备、网络和负载而变。真实游戏帧时间、三台物理设备、物理采集与音质留待实测。 [回归与复现](../verification.md#v100-正式版)
