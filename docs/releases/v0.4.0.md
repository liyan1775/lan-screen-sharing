# v0.4.0 · macOS 桌面视觉与自动恢复公开测试版

本版集成本轮会话确认的全部产品更新：macOS 桌面视觉、默认系统声音、整段邀请加入，以及刷新和短暂断线的自动恢复。

下载[Windows x64 完整测试包](https://github.com/liyan1775/lan-screen-sharing/releases/download/v0.4.0/lan-screen-sharing-0.4.0-windows-x64.zip)，完整解压后打开“先看这里.html”。所有参与者应使用同一版程序与桌面版 Edge 或 Chrome。

## 本版变化

- 沿用用户暂定的 Apple-inspired macOS Desktop UI：中性深浅背景、蓝色主操作、轻量工具栏、列表与成员列、分组设置、消息气泡，减少装饰、厚边界和大面积投影。
- 默认共享画面、系统声音与房间语音。浏览器仍需允许系统音频；无音轨时明确选择无游戏声音继续或取消，不静默发布。
- 房间内复制一段完整邀请，朋友在“手动加入”中整段粘贴、按 Enter 即可。兼容旧复制格式，分别填写三项收进备用入口，附近房间一键加入保留。
- 房主刷新和成员短暂断线不再立即结束房间或删除身份。30 秒内自动重试并恢复原房间、原席位；活跃页面保留采集并重新建立媒体连接。
- 刷新后自动恢复收看；麦克风与屏幕必须重新点击开启。正在分享者刷新后释放已消失的采集，共享席位仍可由原房间成员接续。
- 主动离开、结束房间、退出程序会取消恢复并清除缓存。旧连接的迟到关闭不能删除新连接；在另一个页面恢复时，原页面退出，避免相互接管。
- 关闭最后一个页面后，本机程序约等待 30 秒再退出，方便刷新重新接入。

## 验证与边界

已执行 Go 全包测试、142 项 Node 测试、10 项三人合成媒体回归和最终 EXE 的完整前端浏览器检查。包括房主／成员刷新、连接失败后多次重试、原身份与席位、麦克风与共享连续性、主动退出后刷新不重新加入、文字、全屏及无障碍回归。实际服务资源与当前源码逐项核对，截图与运行证据见[验证说明](../verification.md)。

HIG 回归与视觉验收分开：自动检查覆盖 21 个状态，未发现自动识别的 violation，14 条 incomplete 仍待人工判断；视觉方案已由用户暂定，平台差异见[独立视觉报告](../design-research/macos-desktop-visual-acceptance.md)。这些结论不等于 Apple 官方认证或完整辅助技术认证。

恢复信息仅在当前标签页的 sessionStorage 中保存并绑定本机服务实例；不保存主控凭证。超过保留期、程序重启、浏览器禁用存储或原房间已结束后，需要重新加入。刷新会清空本机文字历史。

本版仍为公开测试版，EXE 未数字签名。未完成真实屏幕／麦克风、三台物理设备、系统声音隔离听感、后台游戏帧率、不同分辨率鼠标捕获及真实读屏软件验收。浏览器捕获的系统声音即使隔离未确认也可能包含房间语音。
