# v1.1.1 正式版 · LAN / 分享

在 `v1.1.0` 基础上的界面体验打磨版本：彻底恢复入口页原有的清爽整体感，将指定查找地址自然融入「设置 → 局域网」，并统一改用简洁直观的日常文案。

## 改进内容

1. **入口页恢复整体感与呼吸感**
   - 移除入口页底部常驻的地址输入卡片，首页回归原本居中平衡的「附近的房间 + 主卡片 + 底部轻量提示」布局。
2. **「指定查找的地址」归位「设置 → 局域网」**
   - 在「设置 → 局域网」的「当前网卡」下方以细分割线自然融入地址管理，不套额外小卡片，在房间内即使网卡不可切换也可随时增删。
   - 展开入口页底部「未发现房间？查看检查方法与诊断」后，点击「添加查找地址」可直接弹出设置并自动滚动、聚焦到地址输入框；关闭设置后键盘焦点自动回到原位置。
3. **统一简洁克制的日常文案**
   - 去除「校园网直连探测」「探测」等偏技术表述；「手动加入」默认勾选开关同步更新为「记住该地址，下次自动显示房间」。
