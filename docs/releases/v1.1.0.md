# v1.1.0 正式版 · LAN / 分享

基于真实校园网与硬件编码实测反馈打磨的新版本：补齐**单浏览器标签页共享**、**校园网好友 IP 单播探测**、**默认锁定清晰度不静默降级**，以及**暗色模式全站下拉框与选字可读性修复**。

## 新增与改进

1. **支持共享单个浏览器标签页（看视频专用）**
   - 打游戏继续选「整块显示器」；和朋友一起看 B 站、番剧或网页视频，可以直接选「单个浏览器标签页」——绕开 Windows 整屏抓屏撞上视频覆盖层掉 15 帧的问题，自带纯标签页声音且不暴露桌面隐私。
   - 自动在选择器里隐藏 LAN / 分享 自身标签页，防止画面套娃或语音回声。
2. **校园网 / 屏蔽广播局域网也能自动发现房间**
   - 附近房间查找新增有限广播（`255.255.255.255`）与多路去重，点击「刷新」立刻发起一轮主动探测。
   - 新增「常用好友 IP 直连探测」（本机最多保存 8 个私网 IPv4）：手动加入成功一次后默认自动记住好友 IP（可取消或随时移除），下次只要好友开启公开房间，即使校园网禁用了二层广播和组播，房间也会通过安全单播探测自动出现在「附近的房间」里。
3. **默认锁定清晰度，不再静默降分辨率**
   - 共享端默认采用清晰度优先策略（`maintain-resolution`），优先守住 1080p 清晰度，避免短暂负载波动把画面锁死在 720p。
   - 一旦浏览器实际编码尺寸低于目标档位，共享端左上角画质胶囊会立刻以琥珀色提示显示真实尺寸（例如 `实发 720p · 目标 1080p`），恢复、切档或停播后自动清除。
4. **暗色模式下拉列表与全站可读性修复**
   - 修复深色主题下设置页 5 个原生下拉框弹出列表“白底白字”看不清的问题，统一为不透明高对比度配色，同时优化全站选中文字高亮、昵称输入框与禁用状态文字在深浅双模式下的可读性。
5. **宣传页冷加载开屏提速**
   - 首屏以下高清截图改为按需懒加载，首屏星环光晕改用轻量离屏缓存并在预热稳帧后起播，显著改善公网首次打开的流畅度。
