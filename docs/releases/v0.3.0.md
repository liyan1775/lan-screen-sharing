# v0.3.0 · 前端改版公开测试版

本版将两轮设计探索接入真实房间，并完成独立 Apple HIG 设计审查：37 项适用要求通过，未关闭设计阻断为 0。审查结论绑定实际程序与服务资源，详见[独立报告](../design-research/apple-hig-independent-review.md)。

入口以附近房间为中心，语音阶段把成员和个人声音控制放在一起，观看阶段让画面成为主要内容。入口与语音跟随系统浅深外观，观看时使用深色。全屏保留麦克风、声音、文字和退出入口；支持键盘及200%文字放大。设置与诊断分层，结束/退出先确认，远端共享不会打断正在进行的设置任务。

新增真实房间文字交流，走已认证成员之间的 WebRTC DataChannel，不依赖外部服务。本机仅保留最近100条，离开或刷新后清空。最多三人语音及轮流共享整屏；两轮模拟体验实验室作为独立HTML附件保留，不连接真实房间。

所有参与者使用同一 0.3.0 Windows x64 包和桌面版 Edge 或 Chrome。完整解压后先打开包内“先看这里.html”。EXE 尚未数字签名。系统声音模式在隔离未确认时仍会发送已捕获声音；分享者可主动停止系统声音。停止屏幕共享会保留语音；本机分享者选择“只聊语音”会停止自己的共享。

已通过 Go 全量测试、133 项 Node 测试、8 项合成媒体端到端测试和完整前端浏览器验收。第一轮实验室源码/单文件各23项通过，第二轮各38项通过。截图、辅助树、哈希和独立键盘证据见[验证说明](../verification.md)。真实采集、三机、声音隔离、后台帧率和不同分辨率鼠标捕获仍属于真实设备公开测试范围。
