LAN / 分享 · 局域网屏幕共享 0.4.0 公开测试版

每位参与者完整解压同一个测试包，在自己的 Windows x64 电脑运行程序。
使用桌面版 Edge 或 Chrome，所有电脑须在可以互相访问的私有局域网中。

1. 双击“局域网屏幕共享.exe”，在浏览器页面操作。
2. 一人创建房间，按需填写房间名、选择是否允许同网发现。
3. 朋友从附近房间加入；找不到时，房主点“邀请朋友 → 复制邀请信息”，
   朋友在首页“手动加入”中整段粘贴，按 Enter 即可。
   分别填写地址、端口和房间码的方式保留在可展开的备用入口。
4. 想说话时点“开启麦克风”并授权；也可以用“文字”交流。
   Enter 发送，Shift+Enter 换行；文字在离开或刷新后清空。
5. 想分享时直接点“共享我的屏幕”，在浏览器选择整个显示器并允许
   系统音频。默认已包含系统声音；一次一人共享，停播后可换人。
6. 观看时点“全屏观看”或双击画面，Esc 返回。停止共享后语音继续。

刷新与掉线
刷新或短暂掉线时，原房间与席位保留 30 秒，页面会自动尝试恢复。
房主刷新不会立即结束房间；活跃页面短暂断线时保留已授权的采集。
刷新后可以继续收看，但麦克风、屏幕需要重新点击开启。
主动离开、结束房间或退出程序后不会自动重新加入。
关闭最后一个页面后，程序约等待 30 秒再退出，便于刷新时重新接入。
程序重启、超过保留期或浏览器禁用存储时，刷新后可能需要重新加入。

声音与网络
系统声音仍需浏览器授权；未捕获音轨时按提示无游戏声音继续或取消。
隔离未确认时已捕获的系统声音仍可能包含房间语音；听感检查不会自动
关声。可主动点“停止共享系统声音”，保留画面和语音。
“只聊语音”暂停本机观看及共享声音；本机正在共享时会停止自己的共享。
发现失败可粘贴邀请加入；网络隔离、VPN、多网卡和防火墙策略可能影响连接。
程序不提供互联网中继，不修改系统防火墙。

本版尚未完成真实屏幕/麦克风、三台物理设备、声音隔离听感、后台游戏
帧率与不同分辨率鼠标捕获验收。EXE 未数字签名。反馈见“测试反馈.txt”，
不要公开完整邀请、本机控制凭证或私人内容。第三方许可随包提供。
