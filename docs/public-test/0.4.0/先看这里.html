LAN / 分享 · 局域网屏幕共享

0.4.0 公开测试版 · Windows x64

每位参与者都需完整解压同一个测试包，在自己的电脑运行程序。使用桌面版 Edge 或 Chrome，所有电脑须在可互通的私有局域网中。

开始使用

  1. 双击“局域网屏幕共享.exe”，在打开的浏览器页面操作。
  2. 一人创建房间，按需填写房间名、选择是否允许同网发现。
  3. 其他人从“附近的房间”加入。找不到时，房主点“邀请朋友 → 复制邀请信息”，朋友在首页“手动加入”中整段粘贴，按 Enter 即可。分别填写三项的方式保留在可展开的备用入口。
  4. 需要说话时点“开启麦克风”并授权；也可打开“文字”，Enter 发送、Shift+Enter 换行。
  5. 想分享时直接点“共享我的屏幕”，在浏览器选择整个显示器并允许系统音频。默认已包含系统声音；一次一人共享，停播后可换人。
  6. 点“全屏观看”或双击画面观看，Esc 返回。停止屏幕共享后，语音继续。

刷新与短暂断线

原房间和席位保留 30 秒，页面会自动尝试恢复。房主刷新不会立即结束房间；活跃页面短暂断线时保留本机采集。刷新后恢复收看，麦克风和屏幕需要重新点击开启。

主动离开、结束房间和退出程序后不会自动重新加入。关闭最后一个页面后，程序约等待 30 秒再退出，便于刷新接入。程序重启、超过保留期或浏览器禁用存储时，刷新后可能需要重新加入。房间文字在离开或刷新后清空。

系统声音与只聊语音

系统声音仍需浏览器授权；没有捕获到音轨时，按提示无游戏声音继续或取消重选。隔离未确认时已捕获声音仍可能包含房间语音；可选听感检查不会自动关声。可主动点“停止共享系统声音”，画面与语音继续。“只聊语音”暂停本机观看及共享声音；本机正在共享时会停止自己的共享。

反馈与测试范围

发现或加入失败时检查网络互通、VPN、多网卡及网络策略；也可粘贴邀请加入。程序不提供互联网中继，不修改系统防火墙。反馈请填写“测试反馈.txt”，不要公开完整邀请、本机控制凭证或私人内容。

本版未完成真实屏幕/麦克风、三台物理设备、声音隔离听感、后台游戏帧率及不同分辨率鼠标捕获验收。EXE 尚未数字签名。更多操作见“快速上手.txt”，第三方许可见“开源组件许可.txt”。
