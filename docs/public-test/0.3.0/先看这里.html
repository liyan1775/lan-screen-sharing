LAN / 分享 · 局域网屏幕共享

0.3.0 公开测试版 · Windows x64

每位参与者都要完整解压同一个测试包，在自己的电脑运行程序。使用桌面版 Edge 或 Chrome，所有电脑须在可以互相访问的私有局域网中。

开始使用

  1. 双击“局域网屏幕共享.exe”，在打开的浏览器页面操作。
  2. 一人选择“创建房间”，按需要设置房间名与同网发现。房主负责保持房间，房主结束或退出会结束房间。
  3. 其他人从“附近的房间”加入；找不到时，房主点“邀请朋友”，朋友在首页选择“手动加入”。
  4. 需要说话时点“开启麦克风”并授权；播放受限时按提示点“启用声音”。不开麦也可以打开“文字”，Enter发送，Shift+Enter换行。
  5. 想分享的成员在“设置”选择模式后点屏幕共享按钮，在浏览器选择整个显示器。一次一人共享，停播后下一人可在原房间分享。
  6. 观看时可点“全屏观看”或双击画面；Esc 退出全屏。停止屏幕共享后，房间和语音继续。

界面与文字

入口与语音界面跟随系统浅深外观，观看时采用深色界面。全屏保留麦克风、文字与声音控制。房间文字仅保留在本机内存中，离开房间或刷新后清空，不提供自动转写。

系统声音与只聊语音

默认不共享系统声音。选择含系统声音的模式后，浏览器已捕获的声音即使隔离不可用或未确认也会发送；可选的听感检查不会自动关声。需要时分享者可点“停止共享系统声音”，画面与语音继续。若没有捕获到音轨，请按页面提示继续无游戏声音或取消重选。

“只聊语音”暂停本机观看及共享声音播放；本机正在共享时选择它会停止自己的共享。之后可选择“恢复观看”。

遇到问题

发现或加入失败时，检查网络是否互通、房主是否允许发现、多网卡/VPN 和网络策略；可以手动加入。没有跨不同局域网的中继。需要反馈时填写同目录的“测试反馈.txt”；截图前遮住房间码、地址栏和私人内容，不要公开本机控制凭证。
