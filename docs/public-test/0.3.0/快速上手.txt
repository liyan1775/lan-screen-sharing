LAN / 分享 · 局域网屏幕共享 0.3.0 公开测试版

每个人完整解压同一个测试包，在自己的 Windows x64 电脑运行程序；
使用桌面版 Edge 或 Chrome，电脑须在可以互相访问的私有局域网。
详细说明请打开同目录的“先看这里.html”。

1. 每人双击“局域网屏幕共享.exe”，在浏览器页面操作。
2. 一人创建房间，按需选择是否允许同网发现；房主退出会结束房间。
3. 朋友从附近房间加入；找不到时，房主点“邀请朋友”查看加入信息，
   朋友在首页填写地址、端口和房间码。不要把 localhost 当作邀请地址。
4. 想说话点“开启麦克风”并授权；播放受限时按提示点“启用声音”。
   也可以用“文字”交流：Enter发送，Shift+Enter换行。
5. 分享者在“设置”选择模式，点屏幕共享按钮，在浏览器选整个显示器。
   同时只有一人共享；停播后下一位可在同一个房间接着分享。
6. 点“全屏观看”或双击画面，Esc 返回。停止屏幕共享后语音继续。

默认不共享系统声音。选择含系统声音的模式时，浏览器捕获到的声音即使
隔离未确认也会发送；听感检查不会自动关声。分享者可主动点“停止共享
系统声音”，保留画面与语音。未捕获到音轨时按页面提示选择继续或取消。
“只聊语音”暂停本机观看；本机正在分享时会停止自己的共享。

入口与语音外观跟随系统，观看时使用深色界面。发现失败可手动加入；网络隔离、VPN、多网卡
和防火墙策略可能影响连接。程序不提供跨局域网中继，也不修改防火墙。

本版真实采集、三机、系统声音隔离、后台帧率和不同分辨率鼠标捕获尚未
完成验收；实际帧率不作保证。EXE 未数字签名。反馈时请填写测试反馈表，
不要公开房间码、本机控制凭证或私人内容。
