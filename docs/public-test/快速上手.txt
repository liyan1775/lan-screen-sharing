局域网屏幕共享 0.2.2 · 公开测试版
所有参加的人都升级到 0.2.2，不能混用旧版。
详细说明：双击同文件夹“先看这里.html”。不需要编程知识或输入命令。

1. 完整解压 → 每个人都在自己的 Windows x64 电脑上双击“局域网屏幕共享.exe”。
   使用桌面版 Chrome / Edge。最多三人，连接可互通的同一个局域网。
2. 一个人点“创建房间”，可填房间名，保持“允许同一局域网发现并直接加入”，
   再点“创建新房间”。公开房间允许同网成员发现并加入，最多三人。
   这个人叫房主，负责维持房间；房主退出时，整个房间结束。
3. 朋友在自己电脑首页“附近的房间”找到它，点一下“加入房间”即可。
   若没显示，等几秒点“刷新列表”。网络不支持发现或房主关闭了公开发现时，
   再用首页“手动加入”；房主展开“备用：手动加入信息”复制给朋友。
   不要用 localhost 当邀请地址，它只表示你自己的电脑。
4. 每个人想说话就点“开启麦克风”并允许使用。没声音先点“启用声音”。
   不开屏幕共享就是纯语音房间。已有画面时可以点“只聊语音”，之后点“恢复观看”。
5. 谁想开播，谁点“选择显示器并开始共享”，在浏览器选择器里选整个显示器。
   同一时间一人共享。有人在播时等他点“停止屏幕共享”，下一人就能接着播，
   不用退房或重发邀请码。整屏会看到切换后的其他应用，请收起私人内容。
6. 想放大画面，点右下角“全屏观看”或双击画面；按 Esc 或点“退出全屏”返回。
   观看区自己的鼠标停住后会隐藏，移动就出现。默认不请求直播主播鼠标；
   当前分享者需要时勾选“共享我的鼠标”。浏览器不支持此设置时，指针仍可能录入。
7. 默认“画面 + 语音（无游戏声音）”。需要游戏声时，当前分享者选择含系统声音
   的模式，再点“选择显示器并开始共享”，选择整个显示器和共享系统声音（若有）。
   正在共享时，先停播再重新选择。隔离未确认也会直接共享声音，无需通过检查。
   “检查是否回声（可选）”只记录听感；选“听到了回声”不会自动关声音。
   自己想关时点“停止共享系统声音”，画面与麦克风继续。
   只有浏览器没有返回声音时，才需选择继续无游戏声音画面，或取消重选。

60 FPS 怎么看？
选择 60 FPS 档后，程序会同时请求采集和发送 60 FPS，但实际取决于设备和浏览器。
“采集设置”是设置值；“实际采集”及逐连接“发送 / 接收”才是运行统计。
若仍约 30 FPS，请把这些统计和“带宽限制 / 编码性能限制”提示一起反馈。
静止桌面不适合判断高帧率，请用持续运动的游戏画面测试。
若只有游戏全屏时掉到 20–30：先全屏玩约半分钟，再返回页面点“复制媒体诊断”。
会保留最近的前后台记录和区间平均值，不必在游戏中切回来读数。
可以再比较一次无边框窗口，仍然共享整个显示器；暂不保证独占全屏达到 60 FPS。

浏览器在后台就掉帧，切回前台恢复？
先保持同一个画面，在主播 Edge → 设置 → 系统和性能 → 性能，
暂时关闭节能/效率模式，再比较前后台。只改这一项，便于判断是不是它造成。
也可把本页加进“始终保持这些站点处于活动状态”；页面“后台直播检查”里
有复制当前页面地址的按钮，启动端口变动后可能需要重新添加。
浏览器和 Windows 进程的节能策略并不完全相同，本项目不能自动解除这些策略。
这是一项排查方法，尚不能保证解决后台掉帧；请复制媒体诊断反馈对比结果。
如果 Edge 仍在后台，Steam 等应用播放视频却让帧率恢复，请记录播放前后数据；
这说明不是固定的后台 30 FPS 上限，仍需区分采集/画面变化与系统调度。
不必为了直播而额外播放视频，也不要把它当成已经修复。

附近仍找不到房间怎么办？
先确认朋友已经建房并允许发现；本版同时尝试局域网广播和组播。
展开“未发现房间？查看检查方法与诊断”，双方各点“复制查找诊断”发回。
如果系统弹出本程序的网络权限提示，按你们信任的网络设置允许通信。
受网络策略限制时可以继续手动加入，不需要关闭系统防护。

怎么退出？
“停止屏幕共享”只停画面和游戏声，语音继续；关闭麦克风只影响自己说话。
“停止共享系统声音”只关本次直播里的系统声音，画面和成员语音继续。
普通成员点“离开房间”；房主点“结束房间”会结束全体房间。
“退出程序”立即退出自己的程序。关闭最后一个项目标签后通常约 3 秒自动退出；
还有其他项目页打开则继续运行。关闭本说明不会关闭程序。
刷新页面可能需要重新加入、开启麦克风或重新共享。

加入失败先核对邀请信息和网络；默认没游戏声是正常情况。
黑屏可把游戏改为无边框窗口，仍共享整个显示器。
卡顿先选 720p · 30 FPS；被系统拦截时记录提示，不要关闭系统防护。
遇到问题填“测试反馈.txt”，写清点了什么、看到或听到了什么。

本版是修正与定位测试包；自动发现、Edge 声音、全屏游戏帧率及捕获鼠标仍需复测。
