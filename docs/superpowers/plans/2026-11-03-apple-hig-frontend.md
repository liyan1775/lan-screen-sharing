# Apple HIG 前端实施与独立验收计划

**Goal:** 将用户选择的 portal / orbit / edge / cinema 视为倾向，完成符合此局域网屏幕共享产品所适用 Apple HIG 的真实前端，并由未参与实现的智能体复验。

**Architecture:** 保留 Go 房间服务和浏览器 WebRTC 媒体生命周期。界面层管理入口、房间和观看阶段；媒体节点保持稳定。文字交流走已认证房间成员之间的 WebRTC DataChannel，不使用外部转写服务。

**Tech Stack:** Go、原生 HTML/CSS/ES modules、WebRTC、Node test、Linkedom；真实浏览器验收工具待当前会话可用性/工具切换确认。

**Spec:** 用户当前目标及 `docs/design-research/apple-hig-independent-review.md` 独立审查矩阵。先前组合仅是倾向，HIG 可用性优先。

## Global Constraints

- 用户已授权继续开发、创建公开 GitHub 仓库及发布；前端完成并经独立审查后才发布。
- 独立审查不能仅凭源码或截图宣布全部合规，未验证事项必须明确记录。
- 不自动采集真实麦克风或屏幕；默认关闭麦克风。
- 不重建或移动播放器，不因布局或音量更新重启媒体。
- 不引入远程字体、分析或转写服务；文字消息只在当前房间设备内存中保留。
- 既有未提交工作保留，不批量回滚；未选择项目许可证之前不擅自授予开源许可。

## Review Focus

- 成员/媒体状态更新期间，当前音量和麦克风控件焦点不丢失。
- 系统深浅模式、文字放大至 200%、窄屏及低高度下，关键状态与操作可用。
- 弹窗可命名、可键盘关闭、焦点可恢复；破坏性操作确认取消后不产生副作用。
- 全屏保留必要媒体控制；退出全屏后媒体保持连续。
- 不开麦的人可用文字参与，发送失败有清晰反馈；不把测试媒体当真实设备验证。
