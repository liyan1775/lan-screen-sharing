# 来源展开 · 实现记录

本方案把真实分享者的成员按钮放在共享画面的来源边，点击该成员打开共享壳的对应声音面板；其余真实成员仍可直接操作。没有共享时共享面成为可停留的语音房间，只显示一行剩余席位。分享者离开/停止后恢复空闲分享动作，不增加队列、声波或假成功状态。

三个阶段按契约注册在 `D.layouts.orbit`；结构和主题解耦。入场覆盖可发现、搜索、无房、受阻及满房；房间处理自己/他人分享、无系统声音、仅语音与连接恢复。观看状态将声音来源和主要动作置于画面之前，窄窗将成员边移到画面上方。真正的系统选择、设备、信令和焦点/弹层控制由共享壳负责。

为了避免直接渲染来源音量面板后，再打开成员弹层产生重复表单 ID，主界面只用 `h.person` 发出成员操作；壳中的成员弹层通过 `h.personAudio` 展示这位成员的真实声源和操作。自己分享时明确“只聊语音会停止你的共享”；当他人分享而选择只聊语音时，只暂停本机画面/系统声音。

已通过 JavaScript 语法检查；使用真实 model、旧公共 helper 和新 helper 对 20 个情境/阶段组合进行 DOM 结构检查，验证根类、成员按钮、麦克风和观看画面存在。这些检查不证明视觉、实际键盘顺序、触摸、真实捕获或三机媒体通过；最终视觉与交互验收由集成页面完成。
