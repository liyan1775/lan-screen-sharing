## 审查依据与适用范围

产品是 Windows 上由本机服务提供的浏览器局域网屏幕共享工具。Apple HIG 是设计指导，不是可以用单项测试获得的 Apple 认证。本审查将逐项评价产品实际使用到的交互类别及跨平台设计原则；Apple 原生 API、硬件、商店集成的专属规定需要明确列出适用性，不能把原生框架调用直接当作网页实现要求，也不能据此跳过无障碍、隐私或用户控制要求。

用户所选的“房间会展开 / 三人一桌 / 只留画面 / 深色影院”仅为倾向。若它与可访问性、清晰度、用户控制或系统偏好冲突，以 HIG 为准。审查不会要求复刻 Apple 界面、使用 Apple 商标或在 Windows 上冒用 SF Symbols 的授权。

## 不适用或受环境约束的项目

- **不适用**：UIKit/SwiftUI/AppKit API、Apple 原生菜单栏与Dock API、Dynamic Island/safe-area硬件API、visionOS空间距离/眼控、watchOS旋钮、tvOS遥控器、CarPlay、Apple Pay、HealthKit、App Store包装。此产品没有这些平台或功能；相应的一般可用性原则仍在矩阵中审查。
- **不能仅凭平台不同排除**：键盘、辅助技术命名/顺序、文字放大、对比度、媒体控制、文字交流替代、权限时机、不可撤销操作确认、动态效果偏好。这些适用于浏览器产品。
- **需要真实环境证据**：Windows 辅助技术、浏览器自动播放限制、原生全屏、真实捕获权限和媒体、真实网络恢复。没有该证据时保留“待验证”，不能用旧原型截图或源码注释代替。

### axe incomplete 的人工处置

最终剩余规则只有`color-contrast`和`video-caption`，没有未处理的`aria-prohibited-attr`。没有把incomplete自动当作通过。

- **卡片、成员、设置、文字标题的对比度：** 结合实际截图和对应样式检查，不透明面板将背景装饰与文字分开；普通文字采用ink/muted，深色面板上的比值分别为14.59:1和7.96:1。浅色muted在surface/raised/soft上分别为6.01、6.44、5.37:1，accent在soft上为5.35:1。高级设置滚动出视口的标签使用相同已核对token。装饰头像为aria-hidden，且可见文字没有覆盖主要信息。
- **控件边界：** 浅色control/soft为3.27:1，深色control/soft为3.91:1，观看按钮边界/按钮背景为4.29:1。状态同时使用文字、图标或边界形状，未仅靠颜色表达。
- **视频来源标签：** 白字在`#111a`深色叠层上。即使底下是纯白视频，合成后的最亮背景约为`rgb(96,96,96)`，白字仍高于6:1。该计算覆盖任意视频画面的更暗背景，而非只验证某一张合成画面。
- **直播视频字幕：** 当前是成员实时提供的共享流，没有作者字幕轨，不能把该axe字幕条目标成“已有字幕”。HIG按情境提供文字体验的设计要求，本产品通过真实房间文字、可键盘使用的消息输入/日志及观看/收听控制提供文字参与途径；关键产品状态也有可见文字和辅助树语义。此项支持本前端的HIG设计判断，不声称共享游戏声音被自动转写，也不授予WCAG直播字幕合规结论。
