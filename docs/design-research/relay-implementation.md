# 接力现场：实现说明

接力现场以当前活动和下一步为主轴：等待时可聊天或分享，他人分享时直接说明需等待停止，收到停播状态后同一活动位置提供分享入口。选择浏览器画面的取消由根层处理，布局不维护或修改房间、麦克风状态，也不模拟请求、排队或自动接棒。只语音的观看者可主动回到画面；本机共享者切换只语音前标明会停止自己的分享。分享者按钮进入对应成员声源，便于分别调整语音和共享声音；本机收听说明放在附近。

入口覆盖搜索、受阻、空房、满房；房间区域覆盖无分享、他人/自己分享、无系统声音与断线提示。画面为公共 helper 的演示画面，控件在画面前方，完整画幅以 contain 展示；布局使用公共 tokens，窄屏换行，控制不依赖 hover。成员区域为安静的在场提示，不制造语音活动。

关键闭环：他人分享 → 当前活动明确等待 → 真实状态变为无分享 → 原位可分享 → 选屏取消仍由根层保持房间与麦克风。最大风险是活动提示仍像额外状态栏，而用户不能发现停播后的动作；还需在实际浏览器里用相同视口与状态对照基线，检查共享者声音面板、窄窗、焦点、取消与交接。原型不证明真实浏览器采集与网络能力。

本次仅完成实现；最终交互、三种主题及 390px/1440px 视觉验收依赖根层整合，尚未声称通过。
