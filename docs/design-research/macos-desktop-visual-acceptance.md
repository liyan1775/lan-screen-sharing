# macOS 桌面视觉改版：独立验收

日期：2026-11-03。对象是 Windows 桌面浏览器中的正式前端源码与独立候选构建，不是旧版 0.3.0 发布包。目标是 **Apple-inspired macOS Desktop UI**；不声称这是 macOS 原生应用或 Apple 官方认证。

用户随后确认“这一版我比较满意，暂定这一版”，本轮视觉方案据此作为后续修改的基线。默认系统声音与单段邀请加入的增量改动及独立验收见[后续功能验收记录](invitation-audio-follow-up.md)；下文构建哈希和原始测试数量保留为视觉基线的历史证据。

该方案已集成到 [0.4.0 公开测试版](../releases/v0.4.0.md)。可随仓库查看的最新实际浏览器证据见[0.4.0 逐页截图](release-0.4.0-qa/README.md)。

## 独立视觉验收标准与结果

| 项目 | 验收标准 | 本轮结果 |
| --- | --- | --- |
| 实际参照 | 至少选择具体 macOS 应用的真实界面，逐页保留参考与实现同屏的证据，记录不同状态和尺寸。 | 通过：四种应用参考，九个页面／状态对照和一张设置局部对照。参考与实现任务、主题和尺寸不完全相同，不能用于像素评分。 |
| 桌面结构 | 房间列表不使用巨型等权卡片；房内成员、共享内容和操作有明确区域；阅读与视觉顺序一致。 | 通过：列表改为紧凑行，房间改为成员列与共享区；DOM 同步为成员后共享区，窄窗依同序堆叠。 |
| 工具栏与控件 | 常用操作有明确主次，图标和文字对齐，关闭／危险操作可辨认；桌面和窄窗不出现不可访问的横向溢出。 | 通过所测状态：轻量工具栏、蓝色主操作、单独的危险颜色和可见焦点；测试覆盖 390px 及 200% 文字。 |
| 背景、边框与材质 | 深浅模式使用中性表面；去掉装饰性圆桌、厚色边和大面积投影；只为任务分组使用边界。 | 通过：列表和成员行用轻分隔，弹窗保留适度层次；观看模式的旧金色也已替换。 |

## 逐页仍存在的差异

1. **房间列表：** 原生屏幕共享参考使用窗口侧栏和设备网格；本项目使用房间状态列表，并保留创建／手动加入入口。
2. **加入与创建：** 当前是浏览器中的居中表单；系统设置参考是原生多栏窗口。输入框、复选框和下拉菜单由 Windows 浏览器绘制。
3. **语音房间：** 当前未共享时显示成员列与共享空状态；FaceTime 参考是视频通话。成员音量及明确状态是本项目额外信息。
4. **设置与声音：** 本项目使用可关闭的网页面板；原生应用的系统材质、下拉菜单细节和窗口行为不同。
5. **观看／全屏：** 本项目的控制区常驻，参考 FaceTime 操作浮在内容上。此处保留原有发现性、全屏和键盘操作方式。
6. **文字：** 本项目的消息位于房间内浮动面板，并显示发送结果；参考是独立会话窗口。
7. **跨页面：** Windows 回退字体为 Segoe UI／Microsoft YaHei UI，图标为项目现有 Phosphor 图标；不具备 SF Pro、SF Symbols 或 macOS 原生系统材质的完全一致表现。用户已暂定本方案，真实 Mac 上的目测仍未进行。

## HIG 与功能回归：独立结果

**本次覆盖的自动化与键盘检查通过；完整 HIG 合规仍待人工复核，不能沿用旧版 37 项结论。**

- `npm test`：134 项通过。
- `go test ./... -count=1`：全部 Go 包通过。
- 最终候选的 `tests/e2e/frontend-hig.spec.js`：通过，使用三实例、真实房间信令和合成媒体；包括创建与加入、文字、音量、共享、全屏、断线恢复、390px、200% 文字、深浅模式和对话框焦点循环。
- axe 对 17 个界面状态报告 **0 个自动识别的 violation**；另有 10 条 `incomplete` 需人工判断，涉及动态／遮罩层对比和实时共享视频字幕。自动结果不等于全部对比度或 WCAG 合规。
- 未完成真实三台设备、真实屏幕／麦克风捕获、读屏软件、任意用户视频字幕及真实音频听感复验。

## 迭代记录

1. 初版对照发现图标按钮被通用图标尺寸规则挤窄；已将尺寸限定到图标容器并复拍。
2. 设置对照发现选项仍是满宽堆叠；已改为标签与控件分列，窄窗改回单列。
3. 观看声音对照发现仍继承旧版金色；已为观看状态明确设置深色中性与蓝色变量并复测。
4. 文字对照发现原行式日志与参考差异明显；已改为发送方可区分的消息气泡，并复测文字、200% 缩放和安全文本处理。
