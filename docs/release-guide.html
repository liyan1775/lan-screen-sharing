LAN / 分享

同一局域网。一起看同一屏。

三步开始共享

  1. 完整解压，打开程序。 每位成员都双击 局域网屏幕共享.exe，在桌面版 Edge 或 Chrome 打开程序提供的本机页面。请让大家使用同一版本。
  2. 加入同一个房间。 一人创建房间，邀请最多两位朋友。朋友可以从“附近的房间”加入，也可以粘贴整段邀请。
  3. 共享整个显示器。 点击“共享我的屏幕”，在浏览器选择整个显示器并确认。按需要授权麦克风与系统声音，系统声音取决于浏览器和采集选择。

边看边聊

从“我的身份”或设置更改昵称与头像颜色。设置里还可以选麦克风、本机试音，以及使用自由麦或按键说话。部分偏好会保存在本机，下次打开时继续使用。

观看画面时，左上角显示实收画质，右上角可以放大细节、截屏或全屏。画中画需要浏览器支持。房间文字里的网页链接可打开，整条消息可一键复制。打开外部链接需要能访问对应网站。

找不到房间？

确认电脑连在能互相访问的私有 IPv4 局域网，例如同一台路由器下。程序会优先推荐实际使用的局域网网卡。自动发现失败时，可检查 Windows 防火墙是否允许专用网络通信，再试整段邀请。

若进入的是旧版本的房间，请所有人先退出旧程序，打开同版程序并重新创建房间。停播后还能继续语音与文字，房主退出后房间结束。
