三步开始共享

  1. 完整解压，打开程序。 每位成员都双击 局域网屏幕共享.exe。程序会优先用 Edge 或 Chrome 打开不带标签栏的独立窗口，和日常网页分开，免得误关共享。打不开独立窗口时，会改用默认浏览器。请让大家使用同一版本。
  2. 加入同一个房间。 一人创建房间，邀请最多两位朋友。朋友可以从“附近的房间”加入，也可以粘贴整段邀请。
  3. 选择要共享的内容。 点击“选择内容并开始共享”，在浏览器的选择窗口中按需要选择：
    • 整个屏幕适合打游戏或展示多个软件。想让朋友听到游戏声时，在浏览器选择器中开启共享音频。
    • 单个浏览器标签页适合一起看 B 站或网页视频，帧率更稳，也不会露出桌面。开启共享音频后，只分享所选标签页的声音。
    • 单个应用窗口适合只展示一个软件。在浏览器选择窗口里点“共享”就会立刻开始，只传送该窗口的画面，不传送应用声音。房间语音照常使用。

边看边聊

想收起画面继续聊天时，共享者点击“停止共享”即可，房间语音不受影响。进房后如果暂时听不到对方声音，不必刷新页面，直接点击界面提示里的“重试语音连接”或“启用声音”即可。

从“我的身份”或设置更改昵称与头像颜色。设置里还可以选麦克风、本机试音，以及使用自由麦或按键说话。部分偏好会保存在本机，下次打开时继续使用。

观看画面时，左上角显示实收画质，右上角可以放大细节、截屏或全屏。画中画需要浏览器支持。房间文字里的网页链接可打开，整条消息可一键复制。打开外部链接需要能访问对应网站。

1080p60 最高 15 Mbps，720p60 最高 8 Mbps，实际随画面与网络变化。

找不到房间？

确认大家连在能互相访问的局域网，例如同一台路由器下。自动发现不到房间时，点“手动加入”，粘贴朋友发来的整段邀请。默认勾选“记住该地址，下次自动显示房间”，也可在“设置 → 局域网 → 指定查找的地址”里管理这些地址。

如果手动加入也失败，检查 Windows 防火墙是否允许专用网络通信。

若进入的是旧版本的房间，请所有人先退出旧程序，打开同版程序并重新创建房间。停播后还能继续语音与文字，房主退出后房间结束。
