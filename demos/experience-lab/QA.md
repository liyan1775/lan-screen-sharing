# 设计体验实验室验收记录

2026-11-03 本地 HTTP 预览的浏览器检查与原图同尺寸对照记录在项目根目录 [design-qa.md](../../design-qa.md)。本记录只覆盖模拟原型，不证明真实局域网、麦克风、系统声音、游戏画质或性能。

- 原图与当前实现分别以 1586×992 像素、相同主要情境并排比较，检查了门牌、围桌和观看声音面板；三组全图及局部证据位于 [对照目录](../../docs/design-research/visual-fidelity-baseline/)。
- 四种外观可与六种交互结构独立切换；入场、语音、观看各可分别选结构。模拟状态随切换保留。
- 浏览器检查覆盖不同桌面和窄屏尺寸，包括声音键盘调节与焦点、停播接续、断线提示以及短屏主播操作。短屏来源页面允许滚动，防止画面和控件被裁切。
- `npm run experience:build` 生成单文件；`npm run experience:test` 的源码和单文件各 38 项检查通过，覆盖 864 种结构／外观组合。单文件的四张 PNG 与源素材逐字节一致；旧实验室源码和单文件各 23 项状态检查通过。
- 同伴通道改善了成员声音的分组和小屏麦克风的位置；来源展开在 390×650 主播情境下完整显示画面，并避免重复标识分享者。围桌的空屏插画去掉了容易被误解为播放按钮的三角。
- 自动化浏览器的安全策略拒绝 `file://`，所以单文件的直接文件协议可视验收未完成；上述视觉检查针对源码 HTTP 预览，离线单文件已做资源与状态检查。
- 当前原型还未替换正式前端，审美满意度待用户确认；满意后仍需将选定方案接入真实产品并验收，再进行 GitHub 发布。
