# 设计体验实验室

双击 `demos/下一版体验.html` 即可离线体验；开发预览也可从 `http://127.0.0.1:4173/experience-lab/index.html` 打开。点击顶部的结构名称比较整套方案；点击「直接聊语音」或「直接看直播」可在同一情境中比较。「专心体验」会扩大原型，顶部小条则负责模拟朋友开始或停止共享。

两轮设计研究都保留为可交互结构：

- **房间会展开**：从房间门牌进入，名称、人数和共享状态延续到房间里。
- **三人一桌**：同伴围绕中间的活动，声音与自己的麦克风放在各自旁边。
- **只留画面**：观看时画面占主要空间，房间、麦克风和声音操作靠边。
- **同伴通道**：从具体成员进入该人的语音及共享声音。
- **来源展开**：共享画面连接在分享者旁，其他成员保留在一侧。
- **接力现场**：朋友停播后，在活动位置提供自愿开始共享的下一步。

「混合示例」分别采用房间会展开、三人一桌和只留画面。展开「自由组合与测试情境」，可以为入场、语音和观看分别选结构；深色影院、纸白客厅、冷白精密和参考图延伸出的晴蓝灵感四种外观独立切换。方案取舍与研究入口见「研究与互评」及 [设计研究](../../docs/design-research/realignment-comparison.md)。

房间、成员、画面、权限和音轨可用性都是模拟，不采集设备、不连接真实房间。浏览器全屏按钮使用真实的浏览器全屏能力。游戏风景是 AI 生成的演示图，不代表真实游戏直播画质或帧率。此原型尚未替换正式前端。

开发和验收：

```powershell
npm ci
npm run experience:build
npm run experience:test
npm run experience:preview
```

自动检查覆盖结构组合和状态；实际浏览器观察与尚待确认的边界见 [验收记录](QA.md)。设计方向仍待用户体验反馈，满意版本确定后再进入 GitHub 发布。
