# 前端设计实验室

独立离线演示入口是 [前端设计实验室.html](../前端设计实验室.html)。可分别选择入场、语音、观看三个阶段的结构，并搭配三种主题，共 81 种配置；也可选择完整路线、综合预设或模拟情境。它用于比较设计，不连接局域网、不采集屏幕或麦克风；全屏按钮使用浏览器全屏能力。

`npm run lab:build` 将源码打包为单 HTML；`npm run lab:test` 分别检查源码和打包结果；`npm run lab:preview` 在本机预览。三套布局的实现与交叉互评在 [reviews/](reviews/) 中。

源码与独立包各通过 22 项离线 DOM/状态检查。浏览器实际画面现可继续验收，最终证据待补；自动检查不等于浏览器视觉通过或真实媒体采集通过。早期曾因本地文件观察限制无法完成视觉检查，历史情况见 [design-qa.md](design-qa.md)。素材说明见 [docs/assets.md](../../docs/assets.md)。
