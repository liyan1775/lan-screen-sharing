# Edge 对 Portal / Orbit 的交叉评审

本评审基于源码与布局意图；没有浏览器走查，公共 helper 和状态转移的最终行为仍需根入口集成后核验。结构与三套主题 token 可独立组合，以下建议不绑定风格。

## Portal

**可取之处与取舍**：发现页将人数、共享状态和剩余位置一起放在房间对象内，满员禁用有文字说明（`layouts/portal.js:11–19`）；进入房间后沿用房间标识，路径连贯。代价是房间对象和身份区占用较大空间，观看时画幅比 Edge 小。纯语音直接提供观看或开始共享，操作区复用公共控件（`portal.js:35–38`），可以让共享占用及自己的停止操作跟随 helper；停止后保留麦克风属于根状态逻辑，单看布局无法确认。

**需尽快处理**：

1. `layouts/portal.js:41` 无论 `s.presenter` 是否存在都调用 `h.screen(s)`。契约只保证其展示画面和断线覆盖，没有保证空共享时自动切换空态；停止共享后可能仍显示演示帧。应在无共享者时明确渲染空态和 `h.shareButton(s)`，或由根入口明确保证 `h.screen` 的空态契约。
2. `layouts/portal.js:41` 观看区只提供 `h.controls(s)`；契约列出的 controls 不包含全屏，header 也未保证全屏。应增加 `fullscreen` 按钮，或确认根入口提供等价入口。

**可访问与异常**：CSS 有显式焦点、窄窗单列和减少动态效果（`layouts/portal.css:52–65`）；连接异常由 `h.notice(s)` 和画面覆盖负责，不自行声称连接成功。窄窗实际换行与全屏可见性仍需集成后验证。

## Orbit

**可取之处与取舍**：语音阶段把本机麦克风和远端音量放在各自位置，空位也有明确含义（`layouts/orbit.js:6–21`）；共享中提供返回观看和 `h.shareButton(s)`，可继承占用禁用和自己的停止操作（`orbit.js:24–28`）。三人平权的结构直观，但每个座位都展开音量控件，窄窗会纵向变长；系统声音仍由声音弹层处理。停止后麦克风保留需要根状态逻辑验证。

**需尽快处理**：

1. `layouts/orbit.js:10,21` 把同一个本机 `s.connection` 文案显示在每个成员座位下，断线或重连时暗示每个人的连接均发生变化；状态中没有每个成员的连接信息。应把该状态放在房间级提示中，或明确标为“本机连接”。
2. `layouts/orbit.js:52` 观看区同样没有契约保证的全屏入口；应增加 `fullscreen` 按钮或确认根入口提供。

**可访问与异常**：独立音量 input 有 label、output 和明确静音标签；焦点、窄窗纵向排列及减少动态效果均有对应样式（`layouts/orbit.js:19`、`layouts/orbit.css:54–72`）。共享占用规则由 helper 决定；断线提示由 `h.notice(s)` 和 `h.screen(s)` 提供，实际状态和键盘流程仍待集成验证。

## 综合配置建议

以 Portal 的发现入口呈现房间容量与共享状态，以 Orbit 的语音座位表达每个人的音量关系，以 Edge 的观看结构保留最大画面；主题作为独立选择。公共层统一全屏、声音弹层、连接状态及共享/停止语义，避免各结构重复实现状态转移。最终选择应在真实窄窗、键盘及三种主题组合中验证。
