# Edge 实现说明

- 结构：发现页以可加入的真实房间列表为入口；房间顶栏保留名称、连接状态、邀请和离开。观看时完整 16:9 画面占主体，操作留在边缘；没有常驻成员侧栏。纯语音使用紧凑成员标记和可返回画面的明确入口。
- 状态：搜索、无房间、搜索受阻、满员、未共享、正在共享及连接异常均依赖共享状态和公共 helper。自己共享的停止操作由公共 controls/shareButton 保持可用；声音弹层由入口统一锚定。
- 样式只使用主题 token，画面背景使用约定的深色；窄窗允许控制区换行，焦点始终可见，减少动态效果。
- 参考：查看了 `03-只留画面.png`。借用画面优先与边缘操作的构图，不把参考图当页面背景，也不复刻截图中隐去的必要操作。
- 验证限制：按协作约定未启动浏览器或服务，未进行截图或真实交互验收。
