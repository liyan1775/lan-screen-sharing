# 集成源码审阅

范围：`app.js`、`ui.js` 与 Edge 布局及公共样式的接口。以下为静态源码证据，未启动服务或浏览器；没有重复执行根代理的测试，也不据此声称完成视觉或交互验收。

## 需要修复

1. **Edge 禁用共享按钮的视觉状态被覆盖。** `layouts/edge.css:45–46` 对所有控件设定 `.88` 透明度并对共享按钮设为 `1`，选择器比 `styles.css` 中 `.d-button:disabled` 更具体。`ui.js:14–16` 在其他人共享或连接未恢复时确实禁用按钮，但 Edge 中可能看起来仍可操作。建议为 Edge 的禁用按钮添加更具体的样式，并保留明确文字。
2. **实验室复制弹窗关闭后无法恢复到触发按钮。** `app.js:11–14,56–59` 只记录画布内焦点，而 `app.js:184` 从画布外的实验室按钮打开复制弹窗。`app.js:55` 关闭时没有可恢复的目标。应保存画布外触发元素或单独保存实验室按钮。
3. **比较面板的键盘退出丢失焦点。** `app.js:207–208` 用 Escape 隐藏包含当前焦点的面板，`app.js:183` 应用综合方案后也隐藏面板，却没有归还焦点；点击关闭分支 `app.js:182` 已有返回比较按钮的做法。建议这两条路径统一归还焦点。
4. **复制失败回调存在关闭弹窗后的空引用。** `app.js:156` 异步剪贴板写入失败时重新查找 `combo-text`，若用户先关闭面板，该节点已不存在，读取 `box.select` 会抛错。应判空并给出合适的失败提示。

## 已核对的接口

- `ui.js:33–39` 返回的 `.d-controls` 及五个直接子按钮类与 `edge.css:41–46` 的选择器一致。共享按钮通过 `ui.js:14–16` 根据状态生成停止、占用禁用或开始动作；停止动作在 `app.js:140` 不修改麦克风状态。
- 声音按钮通过 `app.js:143` 将点击元素传给弹层；`app.js:71–77` 以锚点相对画布计算位置，重绘后按动作重新查找。位置使用估算高度，实际小窗口、滚动及面板内容尺寸仍需目测验证。
- `ui.js:41–47` 将本机成员排除在远端语音列表之外；自己是共享者时不提供本机重复收听的系统声音滑杆，并说明声音发送给朋友。这是模拟界面，不涉及真实音频播放验证。
- `edge.js:45–48` 在无共享者时渲染空态；有共享者但断线时 `ui.js:29–31` 显示等待连接而非上一张演示图。`app.js:140,164` 停止共享后也离开观看状态。
- 未入房时 `app.js:184` 可以打开组合弹窗；`app.js:131,154–157` 明确放行复制动作并提供手动复制回退。复制成功依赖环境提供剪贴板权限，不能仅由源码保证。
- 画布内弹窗打开时选取可聚焦元素；Escape 关闭弹窗，模态对话框提供 Tab 循环（`app.js:56–59,206–216`）。声音和房间菜单是非模态浮层，不做焦点循环；键盘穿出后浮层是否应关闭仍需实际体验判断。
